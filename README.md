# BeeTrack™ v3.0: Constraint Relief for Data Center Procurement

> **Reduce procurement-driven delays by 30-50% within 90 days.**

## The Problem
Data center commissioning dates slip because procurement teams decide 18+ hours too late.

## The Solution
BeeTrack detects delays, routes decisions, validates options, executes in 30 seconds.

## Quick Start
```bash
docker compose up
```

Backend: http://localhost:3000
Frontend: http://localhost:5173

## Architecture
- Backend: NestJS + PostgreSQL + Redis
- Frontend: React 18 + Vite + Tailwind
- Notifications: Twilio SMS + Slack
- Jobs: BullMQ
